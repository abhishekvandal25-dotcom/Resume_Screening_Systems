# AI Resume Screening System

An AI-powered Resume Screening System developed using Python and Flask. The application allows users to upload resumes, compare them with a job description, and calculate a resume match percentage.

## Features

- Upload PDF resumes
- Extract text from resumes
- Compare resume with job description
- Calculate resume match percentage
- Display matched skills
- Display missing skills
- Professional user interface


## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- PyMuPDF
- Scikit-learn
- Pandas
- NumPy
